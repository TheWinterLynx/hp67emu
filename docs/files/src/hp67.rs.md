# `src/hp67.rs`

## Purpose
Provides a temporary UI-facing calculator state so the photographed front panel can be exercised before the real electrical machine exists.

## Why it exists
The UI was built before ACT/ROM/RAM emulation. Without this shim there would be no convenient way to test key hit areas, power/mode switches or LED optics during frontend development.

## Relationships
Consumed by `app.rs`, `panel.rs` and `ui/sliders.rs`. It is deliberately separate from the future reusable HP-67 model under `src/machines/hp67/`.

## Responsibilities
Hold temporary power/mode/display values, accept semantic `UiEvent`/`KeyAction` input, and provide a formatted display string strictly for UI smoke testing.

## Implementation
Uses a small string-based state machine and direct semantic key handling. The startup `0.00`, arithmetic placeholders and mode toggle are not hardware emulation. This entire file is scheduled for deletion once electrical key scanning, power/reset and display driving are connected.

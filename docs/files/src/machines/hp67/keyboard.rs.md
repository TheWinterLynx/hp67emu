# `src/machines/hp67/keyboard.rs`

## Purpose

Models the HP-67 keyboard as physical key contacts that expose the historical ACT keyboard scan code, without implementing calculator-level key semantics.

## Why it exists

The firmware already contains the real key-dispatch behavior, so a faithful emulator must not translate a UI click directly into operations such as “enter digit 1” or modify calculator registers itself. The missing bridge was the hardware-facing keyboard state that presents the code generated by a closed HP-67 key contact to the ACT input seen by the preserved firmware.

## Relationships

`panel.rs` identifies the physical key held by the user, `hp67.rs` maps that UI contact to `Hp67Key`, and `Hp67Keyboard::sample_into_act()` presents the resulting scan code through `ActArchitecturalState::key_buffer`. The ACT architectural core then executes the existing Woodstock key-dispatch instructions and firmware decides what the key means. The scan-code table follows the HP-67 matrix values used by preserved firmware/reference sources and is written in octal to retain the historical row/column pattern.

## Responsibilities

Represent all 35 physical HP-67 keys, provide their unique source-backed scan codes, retain one closed contact at a time, release that contact explicitly, and expose only the resulting optional code to the ACT. It must not edit numeric registers, invoke calculator functions, dispatch firmware routines itself or synthesize display output.

## Implementation

`Hp67Key` enumerates the complete physical keyboard. `scan_code()` maps each contact to its historical octal code; for example digit `1` is `0o142`. `Hp67Keyboard` stores `Option<Hp67Key>` and provides `press()`, `release()` and `scan_code()`. The current bring-up bridge, `sample_into_act()`, copies only that optional scan code into `ActArchitecturalState::key_buffer` at instruction boundaries. Unit tests require 35 unique codes, pin the digit-1 value and verify that closing/releasing a contact only drives or clears the ACT key input.

# `src/ui/classic_display.rs`

## Purpose
Draws the current photorealistic HP Classic-style LED emission over the photographed display glass.

## Why it exists
The source photograph supplies the bezel/filter/reflections but cannot show dynamic numbers. The application therefore needs a renderer for the physical LED geometry until electrical display scanning becomes the source of truth.

## Relationships
Called by `panel.rs`. It is a UI renderer, not the future 1818-0268/1820-1749 electrical model. Later it should consume per-segment intensity generated by `src/machines/hp67/`.

## Responsibilities
Map the 15 physical positions, segment shapes, optical color/glow and current temporary display field into egui drawing primitives.

## Implementation
Uses calibrated physical dimensions and segment geometry, converts temporary text into 15 display cells, and draws only emitted light on top of the photographed glass. The text-to-cells conversion is transitional and must disappear from the fidelity path once display scanning is electrically emulated.
